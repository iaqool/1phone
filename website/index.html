THE RULE

A campaign slot tied to the token, not a wallet list.

Wallet addresses can change. OnePhone keys the registration receipt to the SGT mint within a campaign, so the same token cannot take a second slot there.

01 / VERIFY
◎

Prove current ownership

The client reads the wallet's SGT. The Solana program independently checks the token and the signer before accepting registration.

02 / RECORD
▣

Write one receipt

An immutable onchain receipt is created for that campaign and SGT mint. A repeat registration for the same token fails.

03 / PREPARE
↗

Review recipients

After the window closes, a read-only exporter prepares a proposed reward list. An operator still reviews and creates any Torque incentive.

What the rule means: one registration per SGT mint per campaign. It does not prove one unique human, and registration itself does not pay a reward.
